# 1. แผนผังโครงสร้างไฟล์โปรเจกต์ Apps Script

ระบบ **IT Security & Cybersecurity Governance System** (ISMS) — กองทุนประกันชีวิต

> โปรเจกต์ Apps Script เป็นโครงสร้าง "แบน" (ไม่มีโฟลเดอร์ย่อยใน editor) ไฟล์ `.gs` คือโค้ดฝั่ง Server, `.html` คือหน้าบ้าน/ส่วนรวม

## รูปแบบ include (ใช้ CSS/JS ร่วมกัน)

ทุกหน้า HTML ใช้ `HtmlService.createTemplateFromFile()` + ฟังก์ชัน `include_()` ใน Utils.gs:

```html
<?!= include_('Styles'); ?>      <!-- ใน <head> -->
<?!= include_('JavaScript'); ?>  <!-- ก่อน </body> -->
```
